# 从 0 开始：你现在要做什么

目标：先把“网站 + 智能体流程”的工程闭环跑通，再逐步接入外部工具。

## 现在这个版本能做什么

- 打开网页，输入一句话（例如“计算安吉县2023年生境质量和碳储量”）
- 后端会创建一个 Job，并把阶段推进写入 SQLite
- 默认是 `PIPELINE_MODE=mock`：不会真的跑 SAGA/InVEST，只会把“规划/匹配/产物目录”流程跑通

## 你接下来最关键的 3 个准备

1. 安装并验证 SAGA GIS（后面才需要）：
   - 你需要能在命令行运行 `saga_cmd`（或记下它的绝对路径）。
2. 准备安吉县数据的“最小文件清单”（后面才需要）：
   - 2023 LULC（GeoTIFF）
   - AOI 边界（shp 或 geojson，可选）
   - LULC 图例/分类表（像元值→地类名）
3. 确定要用哪个大模型供应商（可选）：
   - 支持任何 OpenAI 兼容接口（DeepSeek / 通义 / OpenAI 等）。
   - 没有 Key 也能跑（会走规则兜底，只支持安吉县）。

## 最小演示口径（给导师看）

- 演示输入：
  - “计算安吉县2023年生境质量”
  - “计算安吉县2023年碳储量”
  - “计算安吉县2023年生境质量和碳储量”
- 演示输出：
  - job_id、阶段列表、最终结果 JSON（mock 结果）
