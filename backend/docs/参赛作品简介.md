# 参赛作品简介

作品名称：EcoInvest-GPT：生态环境智能化分析平台

EcoInvest-GPT 面向“AI+环境工程”应用场景，以浙江省安吉县为案例地区，将 AI 智能体、GIS 自动化处理流程与 InVEST 生态系统服务评估模型相结合，构建面向县域生态环境监测的智能化分析平台。平台基于 2019—2023 年土地利用数据，支持用户通过自然语言交互完成研究区、年份和模型任务配置，自动调用数据裁剪、土地利用重分类、参数配置、InVEST 生境质量与碳储量模型运行、结果制图和报告生成等流程。作品将传统依赖人工操作的 GIS 与生态模型分析过程封装为可交互、可复用、可扩展的智能分析链路，降低环境工程研究中空间数据处理和生态系统服务评估门槛，为县域生态环境动态监测、生态保护成效评估和国土空间规划决策提供辅助支撑。
